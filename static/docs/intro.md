# Bem-vindo ao DIGIKITS LAB

O **DIGIKITS LAB** é o espaço técnico da DIGIKITS para eletrônica, programação e projetos maker.

Aqui você encontrará documentação de placas e módulos, pinagens, exemplos de código, tutoriais, projetos e guias.

## Como usar

Escolha uma categoria no menu lateral ou use a busca do site.

> Esta primeira versão estabelece a estrutura do LAB. O conteúdo será ampliado progressivamente.

Quando um projeto precisar de componentes, você poderá encontrar os produtos correspondentes na [Loja DIGIKITS](https://www.digikits.com.br).
