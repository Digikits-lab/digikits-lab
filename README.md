# DIGIKITS LAB

Site de documentação, projetos, tutoriais e guias da DIGIKITS, construído com Docusaurus.

## Desenvolvimento local

Requisitos: Node.js 18 ou superior e npm.

```bash
npm install
npm run start
```

O site ficará em `http://localhost:3000`.

## Build

```bash
npm run build
```

## Publicação

Preparado para GitHub Pages e posterior domínio `https://lab.digikits.com.br`.

Repositório: `https://github.com/Digikits-lab/digikits-lab`
