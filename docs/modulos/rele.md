# Módulo Relé

O módulo relé permite controlar cargas por meio de um sinal de controle do microcontrolador.

> Trabalhos com tensão de rede elétrica apresentam risco de choque e incêndio. Para aplicações em rede, utilize instalação adequada e componentes compatíveis.
