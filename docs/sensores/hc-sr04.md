# Sensor ultrassônico HC-SR04

O HC-SR04 mede distância por ultrassom.

| Pino | Função |
|---|---|
| VCC | Alimentação |
| TRIG | Disparo |
| ECHO | Retorno |
| GND | Terra |

> Com placas de 3,3 V, verifique a compatibilidade do sinal ECHO e use adaptação de nível quando necessário.
